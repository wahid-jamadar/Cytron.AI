# hospital_management_system

A comprehensive Hospital Management System with modules for patient, doctor, appointment, billing, pharmacy, laboratory, medical records, staff management, and admin dashboard.

## Features
* Patient Management
* Doctor Management
* Appointment Booking
* Billing
* Pharmacy
* Laboratory
* Medical Records
* Staff Management
* Admin Dashboard
* JWT Authentication
* Role-Based Access Control
* Dockerization
* Swagger/OpenAPI Documentation
* Unit Tests

## Quick Start
1. Clone the repository: `git clone https://github.com/your-username/hospital_management_system.git`
2. Configure environment variables: `cp .env.example .env`
3. Start the application: `docker-compose up -d`
